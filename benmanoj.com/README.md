# benmanoj.com - Coming Soon Page

A simple, elegant coming soon page for benmanoj.com.

## Features

- Clean, minimalist design
- Beige color scheme (#F5F5DC)
- Instrument Serif font from Google Fonts
- Fully responsive design
- "Ben Manoj" text in the top right corner
- Pure HTML/CSS with no dependencies

## Deployment

This is a static HTML page that can be deployed to any web hosting service:

### GitHub Pages
1. Push to GitHub
2. Enable GitHub Pages in repository settings
3. Select the main branch as the source

### Netlify
1. Drag and drop the folder to Netlify
2. Or connect your GitHub repository

### Vercel
1. Import the GitHub repository
2. Deploy with default settings

### Traditional Hosting
Upload the `index.html` file to your web server's root directory.

## Local Development

Simply open `index.html` in your web browser. No build process required.
